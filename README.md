# Cloud 9 Sports Bar - Website Project

A multi-page, fully responsive static website built for **Cloud 9 Sports Bar** in Umhlanga, South Africa. Designed with a dark neon aesthetic (`#030712`, deep blue gradients, and blue/red neon glows).

## Live Preview
* **Hosted Live**:(https://drop-4af728dc-eb3.st10510267.workers.dev)

---

## Pages & Features
1. **Home (`index.html`)**: Hero split-screen layout, glowing brand graphics, and clear call-to-action buttons.
2. **About Us (`about.html`)**: Brand story, visual showcase, and venue atmosphere.
3. **Menu (`menu.html`)**: Complete food and drink catalog featuring category jump buttons, price lists, and a fixed background leaf texture.
4. **Events (`events.html`)**: Event announcements with custom uncropped poster classes (`.poster`) and glowing neon accent headers.
5. **Contact Us (`contact.html`)**: Custom blue-scale Google Maps embed, direct WhatsApp action button, interactive hours accordion, and glowing social links.

---

## Tech Stack
* **Markup**: HTML5
* **Styling**: CSS3 (Flexbox, Grid, CSS Variables, Sticky Positioning, Responsive Media Queries)
* **Interactivity**: Vanilla JavaScript (Accordion toggles)
* **Hosting & Deployment**: Netlify / GitHub
